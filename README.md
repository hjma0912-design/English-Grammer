# 형광펜 영문법

초급 영어 문법 14개 유닛을 매일 조금씩 익히는 모바일 학습 웹앱입니다.

- 앱 링크: https://claude.ai/artifact/7WyhoJEmopriqW9Nj86mLb (비공개 상태입니다. 공유 메뉴에서 공유해야 다른 사람이 볼 수 있어요.)

## 파일

| 파일 | 내용 |
|---|---|
| `grammar-notes.md` | 14개 유닛 문법 노트 (설명, 비교표, 기본 틀, 예문, 자주 하는 실수, 확인 퀴즈) |
| `grammar-app.html` | 위 노트 내용을 그대로 쓴 학습 앱 (HTML 파일 하나에 CSS, JS 포함) |

## 유닛 구성

| 그룹 | 유닛 |
|---|---|
| 기초 문장 | 01 be동사 현재형 · 02 be동사 부정문과 의문문 |
| 현재 시제 | 03 일반동사 현재형과 3인칭 단수 -s · 04 일반동사 현재 부정문과 의문문 · 05 현재진행형 |
| 명사 | 06 셀 수 있는 명사와 셀 수 없는 명사 · 07 관사 · 08 인칭대명사의 격 |
| 과거 시제 | 09 be동사 과거형 · 10 일반동사 과거형 · 11 일반동사 과거 부정문과 의문문 |
| 미래와 조동사 | 12 will과 be going to · 13 can, must, should |
| 전치사 | 14 시간과 장소의 전치사 in, on, at |

## 앱 화면

- **오늘**: 하루 루틴 체크리스트 3개(복습 카드, 새 유닛 1개, 예문 소리 내어 따라 읽기), 최근 7일 학습 기록, 연속 학습일, 즐겨찾기 바로가기
- **학습**: 그룹별 유닛 목록, 상태(새 유닛 / 익힘 %), 즐겨찾기, 즐겨찾기만 보기
- **복습**: 오늘 복습할 카드 수, 복습 시작, 복습을 끝낸 날은 추가 연습 10장
- **기록**: 학습한 유닛 수, 연속 학습일, 공부한 날, 푼 문제 수, 정답률, 유닛별 익힘, 기록 초기화

유닛 화면에서는 예문의 핵심 문법이 형광펜으로 강조되고, 스피커 버튼을 누르면 브라우저 음성(en-US, 속도 0.9)으로 예문을 읽어 줍니다.

## 복습 규칙

- 유닛 퀴즈 한 문제가 복습 카드 한 장이 됩니다.
- 카드는 1~6단계 박스에 들어가고, 다음 복습 간격은 1단계 오늘, 2단계 1일, 3단계 3일, 4단계 7일, 5단계 14일, 6단계 30일입니다.
- 처음 푼 문제를 맞히면 2단계(내일 복습), 틀리면 1단계(오늘 다시)에 들어갑니다.
- 복습에서 맞히면 한 단계 올라가고, 틀리면 1단계로 돌아갑니다.
- 추가 연습과 유닛 퀴즈 다시 풀기는 복습 일정을 바꾸지 않습니다.
- 연속 학습일은 퀴즈를 한 문제라도 푼 날을 기준으로 셉니다.

## 저장

학습 기록은 브라우저의 localStorage에 `hl-grammar-v1` 키 하나로 저장됩니다. 기기와 브라우저마다 따로 저장되며, 저장소를 쓸 수 없는 환경에서도 앱은 정상 동작합니다(이때는 기록이 남지 않아요).

## 로컬에서 열기

`grammar-app.html`을 브라우저로 열면 됩니다. 글꼴(Bricolage Grotesque, Noto Sans KR)은 Google Fonts에서 불러오므로 인터넷 연결이 필요하고, 연결이 없으면 기본 글꼴로 표시됩니다.
